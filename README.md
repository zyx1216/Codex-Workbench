# 工作台

本地单机项目集合。仓库内目前并存这些内容：

- **个人工作台（FastAPI v2.9.0，根目录，当前主版本）**：支持自然语言操作、Function Calling、手动粘贴正文、链接和文件输入、RSS 订阅、待处理批量处理、语义搜索与 RAG 问答。
- **个人工作台 v1.0 骨架（`v2/` 目录）**：早期 FastAPI 骨架副本，保留作并行参考。
- **个人工作台（Streamlit v1.5.0，旧版存档）**：计划、日历、笔记、收藏、知识库，代码已从根目录移除，历史版本见 `历史版本/` 与 `versions/`。

## 个人工作台（当前主版本）

技术栈：FastAPI + Uvicorn + SQLAlchemy + SQLite + ChromaDB，前端为原生 HTML/CSS/JS。

- 首页升级为数据看板：4 张统计卡、最近 7 天笔记趋势、今日待办、今日日程和最近笔记横向卡片；
- 设置页支持 zip 一键备份、预检确认和安全恢复，恢复前自动备份当前数据，启动时每天自动备份数据库。

```bash
python -m uvicorn app:app --reload --port 8000
```

或双击 `run.bat`，访问 http://localhost:8000 。

功能：

- 升级 RSS 订阅：可为每个源设置关注主题，抓取时由 AI 判定相关性，不相关内容自动筛掉，支持 AI 筛选和自动处理开关；
- 开启自动处理后，相关内容直接改写并存入笔记库，不经手动确认；抓取/定时任务统一展示发现、待处理、自动保存和筛选统计；
- 被筛掉的链接持久化为 filtered 状态，不再重复抓取和调 AI；相关性与改写结果均缓存 7 天；
- 新增会议记录，复用笔记表，用 note_type 区分普通/会议，记录会议时间、参会人和主题；
- 支持粘贴原始会议记录由 AI 整理成结构化纪要（主题、议题、决议、待办），整理结果确认后才保存；
- 纪要待办可逐条勾选创建工作任务并关联会议笔记，会议笔记同样可被语义搜索和 RAG 检索；
- 新增日程计划与月视图日历，支持日常/旅行/工作/其他四种类型、跨天日程连续显示、地点备注、可选关联笔记和自定义颜色；
- 首页新增“今日日程”区域和今日日程统计，点击日程可直接跳到日历查看详情；
- 新增日常/工作任务管理，支持优先级、截止日期、完成状态和可选关联笔记；
- 首页展示今日待办、未来 7 天即将到期任务，以及任务总数、今日待办和已完成统计；
- 原任务中心改名为后台任务，接口迁移到 `/api/async-tasks`；链接抓取、手动粘贴、批量处理、质量评估和风格重生成仍进入后台任务，接口立即返回任务 ID；
- 后台任务页可查看任务状态、进度、结果和错误；任务运行中每 2 秒自动刷新；
- AI 改写、评估和重生成结果写入本地 JSON 缓存，默认 7 天过期，重复处理可跳过 AI 调用；
- 笔记保存后按向量相似度自动关联最多 5 篇笔记，展开详情可查看和跳转；
- AI 在后台评估改写质量，卡片显示星级评分，低分笔记有红色提示；
- 支持按“通俗 / 精简 / 详细”三种风格重新生成，并同步刷新标签、关联和评分；

- 首页输入弹窗支持“链接抓取 / 手动粘贴”两种模式；
- 链接无法抓取时，可一键切换到手动粘贴模式，并保留原链接作为来源记录；
- 手动粘贴正文由 AI 改写成通俗笔记；未填标题时自动生成标题；
- RSS 待处理队列支持复选、全选和批量处理；
- 批量处理按顺序执行，通过 NDJSON 实时显示进度，成功项直接保存到笔记库，失败项保留并显示原因；
- 单条待处理内容仍保持“先预览、确认后保存”；
- AI 助手基于 LangChain Agent，支持自然语言搜索笔记、创建笔记、管理 RSS 和基于笔记库问答；
- Agent 主路径使用 LangChain `@tool`、`create_tool_calling_agent` 和 `AgentExecutor`；RAG 使用自定义 Retriever；模型不支持工具调用时自动降级；
- 支持 txt、PDF、Word（docx）文件上传、点击/拖拽选择和上传进度显示；
- RSS 源支持添加、删除、单源抓取、全部抓取，新内容按链接去重；
- 支持每天固定时间自动抓取 RSS，可在设置页开关、配置时间；抓取过程和每个源结果写入日志；
- 笔记库支持列表、关键词搜索、标签/分类筛选、展开查看详情、编辑和删除；
- ChromaDB 本地向量库支持语义搜索，新增或更新笔记后自动建立索引；
- AI 对话历史只保存在本次页面会话中，刷新后清空。
