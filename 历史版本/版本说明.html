工作台（第2.1.0版） 2026-09-07 19:03 2.1 数据安全地基自动备份 + 回收站 + XSS 收口（进入 AI 阶段前的安全加固）：
  • 自动滚动快照：导入覆盖前、每日（距上次 >24h）自动深拷贝五大块数据存 localStorage（最多 3 份）；启动时若当前数据为空但有非空快照，弹窗询问是否恢复（不自动恢复）；超过 7 天未导出文件则提醒备份。
  • 回收站软删除：计划/笔记/链接/文档删除后先入回收站（保留 30 天、可还原/彻底删除/清空）；软删除期间子任务关联 id 保留、还原后自动恢复，仅彻底删除/清空/过期清理才级联清 id；侧边栏新增「🗑 回收站」入口（带数量角标）。
  • XSS 收口：修复 marked 加载成功但 DOMPurify（CDN）失效时返回未消毒 HTML 的降级漏洞，改为任一缺失即转义纯文本；新增 safeUrl() 协议白名单，链接 href 只放行 http/https，挡掉 javascript: 等危险协议（为后续存储 API Key 提前收口）。
  • 导出/导入携带回收站数据；快照与元信息不进备份文件。文件夹删除仍为「文件移到根目录」，不进回收站。
